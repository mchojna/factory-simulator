# Local data

The data that local commands write: `demos/` holds the runs of the demos, `records/`
the database of the server and `reports/` the reports of the stress test. Only this
README and `.gitkeep` are tracked.

## Contents

- [.gitkeep](.gitkeep): the .gitkeep file.

## Entry point

Start with [Measures and the record](../docs/development/en/reference/measures-and-the-record.md)
for run archives and [Demos](../demos/README.md) for saved demo results.
