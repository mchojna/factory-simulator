# Local data

The data that local commands write: `examples/` holds the runs of the examples, `records/`
the database of the server and `reports/` the reports of the stress test. Only this
README and `.gitkeep` are tracked.

## Contents

- [.gitkeep](.gitkeep): the .gitkeep file.

## Entry point

Start with [Measures and the record](../docs/reference/measures-and-the-record.md)
for run archives and [Examples](../examples/README.md) for saved example results.
