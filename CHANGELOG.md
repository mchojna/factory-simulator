# Changelog

Every version that changes the rules of the factory, the observation, the measures, the
record or the HTTP interface has an entry here. A run written with one version is
replayed with that version. The format follows
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/).
