# Frozen 0.1.0

The frozen run of steady-market seed 0 with its trace, which
[test_frozen_run.py](../../e2e/record/test_frozen_run.py) replays. No script writes it:
it holds the decisions and responses of [steady-market-0.json](../steady-market-0.json)
and the digests that `frozen_digests` gives with `include_trace=True`, its eight tables
and a ninth, `traces`, indented by 2.
