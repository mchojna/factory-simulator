# API record repositories

The repositories of the record: one module per resource, and the save they share.

## Contents

- [__init__.py](__init__.py): The repositories of the record: one module per resource, and the save they share.
- [manifests.py](manifests.py): The rows of manifests: add, find and list.
- [operations.py](operations.py): The rows of operations: create, append bodies, write, finish and recover.
- [runs.py](runs.py): The rows of runs: find a run, read and insert rows, sum the ledger, add interactions.
- [scenarios.py](scenarios.py): The rows of scenarios: add, find and list.

## Entry point

Start with [__init__.py](__init__.py).
