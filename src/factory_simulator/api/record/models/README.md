# API record models

The mapped classes of the record: the base and one module per resource.

## Contents

- [__init__.py](__init__.py): The mapped classes of the record: the base and one module per resource.
- [base.py](base.py): The base of the mapped classes: the base class, exact decimals, the schema version.
- [manifest.py](manifest.py): The mapped class of manifests: a manifest stored under the identifier of its content.
- [operation.py](operation.py): The mapped classes of operations: an operation, its identity and its body chunks.
- [run.py](run.py): The mapped classes of runs: a run and every table that belongs to it.
- [scenario.py](scenario.py): The mapped class of scenarios: a scenario stored under its manifest and its content.

## Entry point

Start with [__init__.py](__init__.py).
