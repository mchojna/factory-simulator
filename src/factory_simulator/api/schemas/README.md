# API schemas

The models of the HTTP interface: bodies and answers, one module per resource.

## Contents

- [__init__.py](__init__.py): The models of the HTTP interface: bodies and answers, one module per resource.
- [manifest.py](manifest.py): The models of a manifest: the body that describes a factory.
- [run.py](run.py): The models of runs: submissions of decisions and what a run answers.
- [scenario.py](scenario.py): The models of a scenario: the body that describes the conditions of a run.

## Entry point

Start with [__init__.py](__init__.py).
