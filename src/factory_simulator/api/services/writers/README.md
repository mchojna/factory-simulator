# API services writers

The writers: the dataclasses of the engine as JSON, one module per body.

## Contents

- [__init__.py](__init__.py): The writers: the dataclasses of the engine as JSON, one module per body.
- [description.py](description.py): The writer of a description: the description of a run as JSON, hidden parameters out.
- [observation.py](observation.py): The writer of an observation: the observation of a period as JSON, hidden values out.
- [values.py](values.py): The writer of values: the dataclasses of the engine as plain JSON values.
- [world.py](world.py): The writer of a world: the world of a run as JSON in the shape of the record.

## Entry point

Start with [__init__.py](__init__.py).
