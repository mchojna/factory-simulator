# API services

The services the routes call: one module per resource, and the examples and groups.

## Contents

- [__init__.py](__init__.py): The services the routes call: one module per resource, and the examples and groups.
- [examples.py](examples.py): The examples of the package: the example manifest and its scenarios, made at start.
- [groups.py](groups.py): The groups of a manifest: the values they give their members.
- [manifests.py](manifests.py): The service of manifests: create, generate, list and read manifests.
- [readers/](readers/README.md): the readers subdirectory.
- [runs/](runs/README.md): the runs subdirectory.
- [scenarios.py](scenarios.py): The service of scenarios: create, list and read scenarios of a manifest.
- [writers/](writers/README.md): the writers subdirectory.

## Entry point

Start with [__init__.py](__init__.py).
