# Engine draws

The draws: the world of a run drawn from its seed, one module per kind of value.

## Contents

- [__init__.py](__init__.py): The draws: the world of a run drawn from its seed, one module per kind of value.
- [forecasts.py](forecasts.py): The forecasts of demand: their errors, drawn before period 1, and quantities.
- [streams.py](streams.py): The random streams of a run: a stream per key and the uniform numbers drawn from it.
- [values.py](values.py): The values drawn from uniform numbers: ranges, periods, chances, targets, demand.
- [world.py](world.py): The world drawn from the seed: parameters, series, deliveries and disruptions.

## Entry point

Start with [__init__.py](__init__.py).
