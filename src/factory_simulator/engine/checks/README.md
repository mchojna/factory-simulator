# Engine checks

The checks: rules that join several keys or objects.

## Contents

- [__init__.py](__init__.py): The checks: rules that join several keys or objects.
- [groups.py](groups.py): The checks of the groups of a factory: their names, members and defaults.
- [linear.py](linear.py): The check of linearity: no minimum quantity, discount or changeover in a factory.
- [manifest.py](manifest.py): The checks of a factory: the rules that join two or more parameters or objects.
- [scenario.py](scenario.py): The checks of a scenario: the rules that join it with its factory and its horizon.

## Entry point

Start with [__init__.py](__init__.py).
